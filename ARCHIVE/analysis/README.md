# Approved Swipe Analyses

This directory stores analyses Pranay has explicitly approved after a daily swipe-analysis session.

## Workflow

1. Daifu reminds Pranay daily at 11:15 PM Asia/Kolkata.
2. Pranay shares an X URL, pasted text, or screenshot.
3. Daifu captures the original source and analyzes it using:
   - `PROMPTS/swipe-file-builder.md`
   - `PROMPTS/anatomy-of-viral-posts.md`
   - `PROMPTS/swipe-analysis-session.md`
4. Pranay reviews the analysis.
5. Only after explicit approval does Daifu save it here and update `INDEX.md`.
6. Every three related approved analyses may be synthesized into an anatomy guide under `SYSTEM/anatomy-guides/`.

## Filename format

```text
YYYY-MM-DD-<author>-<short-slug>.md
```

## Important distinction

This archive captures reusable structures, angles, and psychological mechanisms. It is not a library of wording to copy. Source text and attribution must remain attached to every analysis.
