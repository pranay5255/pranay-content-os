# Anatomy Guides

This directory contains patterns synthesized from groups of approved swipe analyses.

A guide should normally be created only after at least three approved posts exhibit a related archetype or mechanism. Each guide must:

- Link to every underlying analysis
- Separate repeated patterns from one-off features
- Explain where the pattern works and fails
- Identify context required from Pranay
- Include anti-copying constraints
- Remain a hypothesis until tested in Pranay's own content

Do not overwrite `PROMPTS/anatomy-of-viral-posts.md` with conclusions from a single example.
